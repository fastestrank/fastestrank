# Security Policy

FastestRank takes the security of our services and public distributions seriously.

## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository or in the hosted FastestRank services, please **do not create a public GitHub issue**.

Instead, please report vulnerabilities privately:

- **GitHub Private Vulnerability Reporting**: Submit a private advisory via [GitHub Security Advisory](https://github.com/fastestrank/fastestrank/security/advisories/new).
- **Email**: Send your report directly to `security@fastestrank.com` or `contact@fastestrank.com`.

### What to Include

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the behavior.
- Any relevant logs, request payloads, or configurations.
- Do not include sensitive credentials, personal data, or private API keys in any report.

### Response Expectations

- **Initial Response**: Within 48 hours of receipt.
- **Triage and Assessment**: Within 5 business days.
- **Fix / Disclosure**: We will coordinate with you on fix timelines before any public disclosure.
